What this is

The nine "eye messages" from the game Noita, redrawn pixel for pixel on a grid. Each message is a wall of small eye glyphs. Nobody has decoded them. This page shows them exactly as they appear in the game, and then lets you lay analysis on top without ever changing the eyes underneath.

The main analysis here is isomorphs: places where the text repeats itself in the same pattern, even when the actual symbols differ. They are a classic clue in code breaking, and these messages are full of them.

Quick start

  1. Drag any message to move it. Shift + mouse wheel zooms; Fit all brings everything into view.
  2. Under Show, try Trigram value to see the numbers the eyes are usually read as.
  3. Click Isomorphs, then click any row in the list. Every place that pattern appears lights up, with repeating positions lettered A, B, C.
  4. In the panel, set Show all listed to Cores + envelope to see every pattern at once, and tick Non-nested occurrences only to strip away the duplicates.

Eyes and trigrams

Eye
One glyph. There are five kinds, told apart by where the pupil sits: 0 center, 1 up, 2 right, 3 down, 4 left.
Message
One wall of eyes. There are nine: E1 to E5 (east) and W1 to W4 (west). Rows alternate being shifted half an eye to the right, exactly as in the game.
Trigram
Three neighboring eyes read together as one symbol. They form small triangles: in each pair of rows, the triangles alternate pointing down and up. Trigram 4-color shows exactly which three eyes go together. This way of reading the eyes is the widely accepted one, because it produces clear structure that random readings do not. It is still an interpretation on top of the eyes, which is why the plain eyes are always the base layer.
Trigram value
The three eyes as a number: first × 25 + second × 5 + third. That could run from 0 to 124, but only 0 to 82 ever appear, which is itself one of the known clues.
Position
Where a trigram sits in its message, counted in reading order starting from 0. "E4 68" means the 69th trigram of E4.

Isomorphs, in plain terms

Repeat pattern (isomorph)
Two stretches of text share a pattern when the same positions repeat in the same way, even if the values themselves differ. For example:
12 40 12 7 55 3 55 20 A B A C A B A C same pattern
If both were written with the same hidden key, a repeated pattern like this is a sign the same underlying words may be sitting in both places.
Signature (the letter chips)
The pattern written with letters. Values that repeat inside the stretch get a letter (A, B, C...) and a color; values that appear only once are shown as gray dots.
Class
One pattern, plus every place it appears. The Classes tab lists them.
Occurrence
One of those places: a message and a starting position.
Nontrivial
Contains at least one repeat. Patterns where every value is different are left out: they would match almost any stretch of text and tell you nothing.
Match
Two specific stretches that share a pattern and cannot be extended one more trigram to the left or right without breaking it. This is the most honest unit, because it is exactly as long as the evidence allows. The Matches tab lists them. (Technical name: pairwise-maximal event.)
Offset
How far apart the two stretches of a match start (second start minus first).
Value map
For a match, which value on one side lines up with which value on the other, for example 79 → 63. It is always one-to-one: a value never pairs with two different partners.
Why a match stops
Either extending it would force a value to pair with a second, different partner (breaking one-to-one), or one of the messages simply ends.
Pairwise-maximal realization
A class has one if, somewhere, one of its occurrences is itself a complete match. Classes without one only ever show up as a piece of a longer match.

Core, envelope, and nesting

Core
The part of a pattern from its first repeated position to its last. This is the part actually held together by repeats.
Fringe
Positions outside the core. They hold values that appear only once in the pattern, so almost any value would fit there: weak evidence. They are drawn faded.
· A · B A · B · · [-- core ------] fringe on both sides
Maximum envelope
An occurrence can be part of a longer match with some partner elsewhere. The envelope is how far that longer match reaches. Different partners can reach different distances, so the viewer uses the furthest reach over all of them. With a class selected it is shaded blue; hover an occurrence button to see each partner.
Nested
An occurrence that sits completely inside a longer occurrence in the same message. It is just a piece of the bigger one. Non-nested occurrences only hides these, one occurrence at a time, so a class can keep some of its occurrences and lose others (shown as, for example, 17/20). Partial overlaps are kept. Which occurrences count as nested is decided once, against every pattern, so no other filter can change it.

Counting repeats

Length alone is misleading: a long pattern can be mostly fringe. There are four ways to measure how much repetition a pattern holds. For the pattern A B A C C D D D:

Repeated values: 3
How many different values repeat (A, C and D). This is the Rep column.
Positions in repeats: 7
How many positions are taken up by repeating values (everything except B).
Repeat surplus: 4
How many extra appearances there are beyond each value's first (one extra A, one extra C, two extra D).
Equal pairs: 5
How many pairs of positions hold the same value (A gives 1, C gives 1, D gives 3). This rewards values that repeat many times.

Coverage and show-all colors

Coverage (under Show) labels every trigram with the length of the longest match it sits inside. Red × means no match reaches it.

Show all listed (in the Isomorphs panel) draws every pattern in the current list at once:

  • inside exactly one core
  • inside two or more cores; the number says how many
  • reached only by one envelope, never by a core (with Cores + envelope)
  • reached only by two or more envelopes
  • reached by nothing

How much to trust what you see

Everything drawn here is real: every eye, trigram, pattern and match was checked against the source data when this page was built (see below). What it means is a separate question. Short repeat patterns turn up by chance in any text. Long ones are rare by chance, but judging whether a particular pattern is meaningful needs a statistical test against random text, not just how striking it looks. Treat this page as a place to find things worth testing, not as proof on its own. Faded fringe positions are the weakest part of any pattern.
